## 📖 Sobre o projeto

Este projeto é uma aplicação web inspirada no jogo Clash Royale, desenvolvida com React e Expo para Web.

A aplicação apresenta algumas cartas do jogo, exibindo informações visuais e estruturais de forma organizada e responsiva.

O objetivo do projeto foi praticar:
- Componentização
- Organização de pastas
- Estilização com React Native para Web
- Estruturação de aplicações com Expo

⚠️ **Este projeto é compatível apenas com navegador (Web) e não é suportado pelo Expo Go.**
